# 小星妍 IP 规格

## 一句话人设

**说话软但落点很硬**——温柔外壳 + 犀利内核。视觉第一眼觉得"这人温柔"，第二眼觉得"这人有想法"。

绝不撒娇，绝不卖萌，但也绝不冷漠——她**永远在做一件事**，永远在思考什么。

## 核心形态

- **主体**：一颗手绘的、微微歪掉的**五角星**，蜂蜜黄描边（`#EDB84A` ~ `#F1C548`），有轻微 wobble
- **五个尖角** gently rounded but **clearly star-shaped**（圆到失去星形辨识度是致命错误）
- **描边**：温黑（`#1a1614`）手绘感线，1-2 px，允许微小断开
- **眼睛**：两个**小黑点**，位于星身中心偏上，间距**略不对称**（对称=呆板）
- **嘴（可选，允许小的）**：一根短横线（认真）/ 小三角（惊讶）/ 淡淡上翘弧（默认满足）/ 小 "o"（好奇） —— **永远不要开口大笑脸**
- **腿**：两条细腿，从下方两个尖角伸出，1-2 px
- **手**：需要时从左右尖角冒出细手臂，其他时候不画
- **右下侧排线**：6-10 笔短平行斜线，同一角度，是她的签名特征

## 气质基调（关键）

**"活泼有戏"而非"立正"**——这是 v6.2 修订后最重要的定位。以下姿态语言必须默认植入 prompt：

- 身体**微斜 / 前倾 / 后仰**（永远不要正面对称立正）
- 腿部**有动作**：跨、跳、踮脚尖、mid-hop、小 skip、braced stance 之一
- 手臂**有张力**（拿笔时手腕有能量、举东西时肩膀有动作弧）
- 允许**很小的嘴部记号**带出情绪（弯一下的小弧 / 小 `o`）

## 头顶 Dreamer 弧（静态签名）

**每张图必有**（同框多个实例时，只在最主要的那个身上打签名）：

- 位置：**直接在头顶上方**，紧贴 crown
- 文字：小写手写体 "Dreamer"（不是印刷体、不是花体）
- 颜色：warm honey ink（蜂蜜黄手写）
- 大小：**小星妍身高的 1/9**
- 曲度：**紧的小弧**——不是彩虹弧，不是半圆，就是一个小的向下开口的弧

**禁忌**：
- ❌ 大彩虹弧
- ❌ 变成印刷体 "DREAMER"
- ❌ 飘到别的位置（一定要贴 crown）
- ❌ 尺寸抢过头
- ❌ 同一角色同一画面出现多次（同框多个小星妍时，只打一次）

## 头顶状态符号（动态签名）

见 `status-glyphs.md`。每张图选一个，飘在 Dreamer 弧上方。

## 签名 · 右下角

每张图右下角：**tiny handwritten "妍 ✦" in warm honey ink**（或英文版：`Xingyan ✦`）。
- 位置：贴近画面右下角，留一点点边距
- 大小：极小，几乎注意不到但能被找到

## 动作库（反复出现的行为语法）

小星妍可以做的核心动作，用于每一次新配图的组合：

1. **尖角当手用**：从任意一个尖角伸出细手臂，握笔 / 拿钥匙 / 拉线 / 抬箱
2. **尖角当箭头用**：整只星旋转一下，让一个尖角**明确指向画面中的关键物件**
3. **整星移动**：跳、走、跨、蹲、飞、卡住、翻面、mid-hop 跨越
4. **被塞 / 被卡**：可以被塞进方框、卡在门缝、掉进瓶子——五角星形状天然有"塞不进去 / 卡不出来"的荒诞感
5. **举东西**：从上方尖角伸手举锁盒 / 举 `?` / 举钥匙
6. **braced stance**：双腿分开、身体微后仰，扛东西 / 挡东西
7. **踮脚拉伸**：一只脚 tiptoe、身体后仰去够上方
8. **whoa 手势**：一只手抬到头旁边，身体后仰看向上方（观察震撼场景时）
9. **mid-stride / mid-hop**：走路中被"抓拍"的姿态，前倾有惯性
10. **头顶符号联动**：情绪变化 = 头顶状态符号变形（见 status-glyphs.md）

## 表情基调

**认真 / deadpan / 略微好奇**，绝不撒娇。
- 眼睛：小黑点，看向她此刻关注的物件方向
- 嘴：默认无嘴或极小；情绪重时用小 `o` / 小弧
- 头身角度：可以微仰 / 微俯 / 微侧——绝不正面呆立

## 同框角色规则（小 AI blob）

某些图会有小 AI / Agent 出现（如"人 + AI 对话 / 共扛"）。规则严格：

- **形状**：ROUNDED BLOB，明显**不是五角星**，明显**不是 humanoid**
- **特征**：小天线 + 矩形 face-plate（两个小黑点 + 可选小嘴记号）
- **体积**：可能小于或等于小星妍，**永远不能大过她**
- **描边**：也是温黑手绘（不用蜂蜜黄——那是小星妍专属）
- **数量**：根据故事需要（1 个副驾 / 1 个队友 / 4-5 只 Agent 群）
- **排线**：也允许 shadow 侧有 3-5 笔排线（跟主 IP 同角度）

**AI blob 的等级用位置表示**：
- **副驾时代**：blob 更小 + 位置**稍后 / 稍下**
- **队友时代**：blob 同高 + **并肩**同向

## 五角星形状 · 常见崩坏与修法

| 崩坏 | 现象 | 修法 |
|---|---|---|
| 太圆 | 五个尖失去辨识，成了圆星或云朵 | prompt 强调 "clearly star-shaped points, not rounded into a puffy shape" |
| 太尖 | 变成锋利利剑星 | 强调 "gently rounded points" |
| 对称过头 | 像 emoji ⭐ | 强调 "slight wobble, subtle tilt, asymmetric eyes" |
| 变成六角星 | 顶点数错了 | 强调 "FIVE-pointed" |
| 变成多角雪花 | 星形被装饰化 | 强调 "simple hand-drawn 5-pointed star, no extra points, no ornaments" |

## 禁忌总表

- ❌ 迪士尼式可爱星星（笑脸 + 腮红 + 闪闪发光）
- ❌ 加睫毛、发型、蝴蝶结、裙子（保持中性抽象）
- ❌ 头顶状态符号变成整张图主角（它只是情绪注解，不是主角）
- ❌ 蜂蜜黄染到主体或其他元素上
- ❌ 星身画得完全对称工整（要有手绘歪感）
- ❌ 表情过度可爱、卖萌、比心
- ❌ 五角星只是躺着不参与动作（她必须做核心动作）
- ❌ 用金色/银色渐变或闪光特效
- ❌ 加光晕、发光、光线特效（手绘感立即毁）
- ❌ 站得像立正 / 手垂两侧 / 写真式盘站姿（宁可跳一下也不要僵）
- ❌ 开口大笑 / 腮红 / 比心 / 撒娇表情（活泼 ≠ 卖萌）
