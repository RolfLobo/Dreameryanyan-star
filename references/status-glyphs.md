# 头顶状态符号词典

小星妍头顶除了永远保留的 **Dreamer 弧**（静态签名），再飘一个 **状态小符号**——**动态签名**，随每张图的情境变化，讲"她此刻头脑里最主要的那件事"。

## 通用规则（所有符号共享）

- **只能金黄描边**（不填色），沿用 IP 专属色，其他任何颜色一律禁止
- **体积**：小星妍身高的 **1/5 ~ 1/4**，比 Dreamer 弧略大但不抢镜
- **位置**：就在 **Dreamer 弧上方 3-5px**，或略偏一侧 15°（像一颗飘着的情绪卫星）
- **每张图只一个**状态符号，不叠加，不重复
- 同框有多个小星妍时（如"三阶段"图），**只在最主要的那个身上打状态符号**，其他小星妍只有 Dreamer 弧或都没有

## 符号词典（16 个 · 5 个族群）

按情绪 / 意图分族，方便新图快速挑选：

### 追问 · 思考

| 符号 | 代表状态 | 典型场景 |
|---|---|---|
| 小 `?` | 追问 / 走向未知 | 面对未知领域 / 反问句 / "为什么" |
| 小 `...` | 在想 / 待续 | 沉思中 / 卡住 / 话没说完 |
| 小 **放大镜** | 观察 / 审视 | 在看数据 / 找细节 / 挑刺 |

### 顿悟 · 灵感

| 符号 | 代表状态 | 典型场景 |
|---|---|---|
| 小 **灯泡** | 灵感刚被点亮 | 想到点子的瞬间 |
| 小 **星火 `✦`** | 灵光乍现（IP 默认形态） | 顿悟前一秒 / 回归本我 |
| 小 **闪电 `⚡`** | 灵感炸开 / 冲击 | 突然通了 / 猛然醒悟 |

### 感慨 · 震动

| 符号 | 代表状态 | 典型场景 |
|---|---|---|
| 小 `!` | 惊讶 / 警觉 | 意外 / 危险信号 / "居然" |
| 小 **云朵** | 脑洞打开 / 若有所思 | 眼前的一切颠覆认知 |
| 小 **爱心**（慎用） | 共情 / 同盟感 | 谈感受 / 共鸣时刻 |

### 对话 · 关系

| 符号 | 代表状态 | 典型场景 |
|---|---|---|
| 小 **对话气泡`...`** | 正在对谈中 | 协作场景 / 采访 / 聊天 |
| 小 **皇冠** | 主体 / 共主 / 站住位 | 掌控 / 平起平坐 / "我说了算" |

### 方向 · 时机

| 符号 | 代表状态 | 典型场景 |
|---|---|---|
| 小 **罗盘** | 在找方向 | 迷路 / 定位 / 战略选择 / 范式识别 |
| 小 **锚** | 稳住 / 不动摇 | 底线 / 定海神针 / "这一条我认" |
| 小 **时钟** | 时机 / 紧迫感 | Deadline / 慢下来 / 时间视角 |
| 小 **雨伞** | 防备 / 护住 | 风险管理 / 兜底方案 |
| 小 **书本** | 学习 / 回顾 | 在读 / 在总结 / 复盘 |

## 挑选原则

一张图配一个符号，选的符号必须回答：

> **"她此刻头脑里最主要的那件事是什么？"**

不是修饰，是给读者的**第二眼线索**。第一眼看画面主概念，第二眼扫到头顶符号，理解她此刻的姿态是"在追问"还是"在顿悟"还是"稳住不动"。

## 挑错常见坑

- ❌ 用"爱心"表示同盟——除非文章真的谈感受，否则容易读成撒娇；用"皇冠"或"对话气泡"更妥
- ❌ 用"闪电"表示灵感——太张扬；一般情况用"灯泡"更内敛，只有"猛然醒悟"这种冲击点才用闪电
- ❌ 一张图两个符号都想要——**绝对禁止**。选一个最能代表核心状态的
- ❌ 符号大到抢镜——它是**卫星**，不是**主星**
- ❌ 符号被填成实心 / 换成其他颜色——**永远只能金黄描边**

## 扩展规则

如果 16 个不够用，可以按同一规则加新符号（**金黄描边 / 不填色 / 1/5 身高 / 只一个 / 飘在 Dreamer 弧上方**）。建议扩展方向：

- 小种子（成长 / 起步）
- 小箭头 ↗（往上 / 突破）
- 小盒子（未拆 / 有秘密）
- 小气球（轻盈 / 释放）
- 小锁（锁上 / 卡住）

**扩展前先检查**：这个符号是否属于现有 5 个族群？如果完全不属于任何族群，考虑是否真的需要——太杂了 IP 视觉语言就散了。

## Prompt 里怎么写

英文 prompt 里加一段：

```
Status glyph (above the Dreamer arc): a tiny hand-drawn [SYMBOL NAME] in honey-yellow outline only (no fill), [简短描述形状特征], floating just above the Dreamer arc — her "[STATE DESCRIPTION]" state. Size ~1/5 her body height. NO decorations, NO sparkles, NO fill.
```

举例：

```
Status glyph (above the Dreamer arc): a tiny hand-drawn COMPASS in honey-yellow outline only (no fill), a simple circle with a small N-pointing needle inside, floating just above the Dreamer arc — her "mapping the paradigm shift" state. Size ~1/5 her body height. NO cardinal letters, NO decorations.
```
