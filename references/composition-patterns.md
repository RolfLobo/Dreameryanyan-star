# 构图哲学 · 反差抓手 · 尺寸规则

## 一句话原则

**每张图必须有一个"反差抓手"**——两个区域 / 两个状态 / 两个符号被明确对偶起来，让读者一眼看到"这里在讲一个位移"。

## 6 种最好用的反差抓手

| # | 反差抓手 | 用在什么话题 |
|---|---|---|
| 1 | **翻面 / 折痕** | 前后对比 / 过去 vs 未来 / 优化 vs 定义 |
| 2 | **背对 vs 面对** | 放弃旧 vs 拥抱新 / 走向 vs 逃离 |
| 3 | **一个上方 + 一个下方** | 目标 vs 动作 / 悬空物 vs 举手 / 未来 vs 现在 |
| 4 | **并肩 / 同高** | 平等 / 同盟 / 协作 |
| 5 | **一 vs 群** | 单体 vs 群体 / App vs Agent / 中心 vs 网络 |
| 6 | **合上 vs 打开 / 闭 vs 开** | 旧知识失效 vs 新知识萌芽 / 门关 vs 门开 |

## 尺寸规则

### 3:4 竖版（默认推荐 · 小红书 / 公众号最优）

- **留白**：55-65%（大部分留在上部或四周）
- **构图分区**（三段式）：
  - 上部 30-55%
  - 中部 20-35%（可以是主 IP 或过渡带）
  - 下部 20-40%
- **反差轴**：**垂直方向**——上 vs 下最容易读
- **中文标签**：最多 2 个，分别贴近上部和下部的核心物件

### 4:3 横版（幻灯片 / 排版）

- **留白**：50-60%（大部分留在左右两侧）
- **构图分区**（三段式）：
  - 左侧 30-45%
  - 中间 15-30%（过渡 / IP 位置）
  - 右侧 30-45%
- **反差轴**：**水平方向**——左 vs 右最容易读
- **中文标签**：最多 2 个，分别贴近左侧和右侧的核心物件

### 1:1 方版（社交头图 / 小图标）

- **留白**：50%
- **反差轴**：可以是**对角**——左上 vs 右下
- **中文标签**：**最多 1 个**（方图太小塞两个会挤）

### 三阶段图（特殊构图）

如"Tool → Copilot → Teammate"这类**演进图**：

- **3:4 竖版**：**三个横向 band** 上下堆叠，每 band ~1/3，读顺序 = 演进方向
- 三个 band 之间用**虚线 dashed line** 或**纯留白**分隔（不用实线，太重）
- **Dreamer 弧 + 状态符号只打在最重要的那个实例上**（通常是第一个），其他 band 里的小星妍就是普通角色

## 三处排线的位置策略

排线不是随便加的，是**建立体积和权重**的手艺。三处默认分配（按优先级）：

1. **小星妍身体的右下侧**（6-10 笔）——她的签名，永远保留
2. **主物件的阴影侧**（4-8 笔）——把主物件从纸上"托起来"
3. **地面阴影 / 或第二个物件**（3-5 笔）——把画面"钉"在地上

**角度全图统一**——比如都是 45° 向右下。不允许一处向左一处向右。

## 同框角色规则（详见 xiaoxingyan-ip.md）

- 单角色图：只有小星妍
- 双角色图：小星妍 + 1 只 AI blob（rounded blob, NOT star, NOT humanoid）
- 群体图：小星妍 + 4-5 只 Agent blobs（每只带一个不同的小工具区分身份）

## 中文标签的放置

- **最多 2 个**（英文版最多 4 个：era name + sub-line × 2）
- **贴近它注解的物件**——不用引导线
- **颜色对偶**：过去 vs 未来 = 蓝 vs 红；工具 vs 队友 = 蓝 vs 红；温和 vs 关键 = 温黑 vs 红
- **手写风**，中文标签**每个最多 6-8 字**

## 常见构图崩坏

| 崩坏 | 现象 | 修法 |
|---|---|---|
| 图太满 | 元素堆在中间，没留白 | 删掉一半元素；强制"上部 55% 空白" |
| 反差不清 | 上下 / 左右差不多 | 一侧密集、一侧空白；一侧繁复、一侧极简 |
| IP 抢镜 | 小星妍太大盖过主概念 | 缩小到画面高度的 1/4 - 1/3 |
| IP 太小 | 主概念太大、小星妍被淹没 | 拉大 IP，或减掉一些次要元素 |
| 平均分布 | 元素散在四角，没有焦点 | 集中到一个视觉锚点，其他全空 |
| 排线蔓延 | 排线像网点填满某片 | 严格 3-10 笔一处，其他 NO hatching |

## 编辑插画 vs 信息图 · 分界线

编辑插画（我们做的）：
- **一张图 = 一个论点**
- 大量留白
- 手绘 wobble
- 反差抓手
- 极少文字

信息图（不是我们做的）：
- 一张图塞多个信息点
- 满构图 / 数据密集
- 矢量硬边 / 精确对齐
- 图例 + 数据表 + 标题
- 大量文字

**如果发现图开始像信息图，立刻停下删元素。**

## Anti-slop 构图级

- ❌ 左上角出现标题（"系统架构图" / "流程说明" 之类）——这是信息图特征
- ❌ 图例框 / 图注框 / 边框——编辑插画没有这些
- ❌ 分栏线 / 表格线——用留白分区，不用线
- ❌ 箭头满天飞——最多 1-2 个方向性箭头（橙色）
- ❌ 数字标号 ①②③④——用位置和顺序讲，不用编号
