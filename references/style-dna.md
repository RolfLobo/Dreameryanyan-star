# Style DNA · 小星妍编辑插画的视觉底色

## 一句话哲学

**一张图 = 一个概念 + 大量留白 + 3 处结构性排线 + 反差抓手**

目标是克制、有观点的报刊编辑插画：单一概念、低技术隐喻、大量留白、手绘线条和少量结构性排线。不是可爱贴纸，不是商业卡通，也不是信息图。

## 纸底 · 两种选择

| 情境 | 纸底 | 何时用 |
|---|---|---|
| 温暖、文学、编辑插画感 | Warm cream `#fbf8f0` | 公众号正文配图、书籍插图、有点"读报"感的场景 |
| 干净、现代、通用 | Pure white `#ffffff` | 幻灯片、社交媒体、需要贴到多种背景上的场景 |

**只能选一个**，不允许中间态（不许 `#fdfcf5` 之类的伪白），Anti-slop 里必须明写：
- 用 cream 时禁止 `NO paper texture, NO grain`（防止模型加做旧质感）
- 用 pure white 时禁止 `NO cream, NO beige, NO tint, NO texture`（防止模型偷偷加暖色）

## 留白率

- 3:4 竖版：**55-65% 留白**
- 4:3 横版：**50-60% 留白**
- 1:1：**50% 留白**

留白**必须成片**，不能是"到处一点点"——通常是画面**上部**或**四周边缘**大片留出，让主概念在中间偏下或中间偏一侧集中出现。

## 颜色系统 · 稀缺是关键

| 颜色 | HEX（近似） | 用途 |
|---|---|---|
| **蜂蜜黄 Honey Yellow** | `#EDB84A` ~ `#F1C548` | 只用于小星妍身体、Dreamer 弧、头顶状态符号（描边） |
| **温黑 Warm Black** | `#1a1614` | 主线稿、排线、大部分手写文字、大部分物件 |
| **红 Red** | `#E43C31` ~ `#D93A3A` | **关键判断 / 反问点 / "未来"侧标签**（一张图最多 1-2 处） |
| **蓝 Blue** | `#2F6EE0` ~ `#3670D8` | **旁注 / "过去"侧标签 / 系统状态说明**（跟红对偶使用） |
| **橙 Orange** | `#E86B27` | **动作箭头 / 主路径 / 转变符号**（当画面需要一个方向指示器时） |

**核心稀缺规则**：
- **蜂蜜黄绝不外溢**——不允许染任何其他物件、任何背景、任何标签。染错的瞬间 IP 就散架。
- **红 + 蓝** 只用于**对偶标签**（过去 vs 未来 / 界面 vs 协作 / 工具 vs 队友）。如果只有一个标签，用温黑。
- **橙**只出现在需要"箭头"或"主路径"的图里。当红蓝已经在打对偶时，避免加橙——三色齐上会散。
- 每张图**最多 3 种彩色**（蜂蜜黄 + 温黑 + 一到两种批注色）。

## 手绘线条

- **线宽**：1-2 px 感的手绘感线条（不是矢量硬边）
- **抖动**：有轻微 wobble，能看出手的痕迹
- **不闭合**：允许小星妍身体、物件的边线有微小断开，那是编辑插画的呼吸感
- 严禁：光滑贝塞尔 / 卡通粗描 / 3D 高光 / 塑料反光

## 排线语言 · 三处规则

**结构性排线是小星妍风格最容易辨识的签名之一。** 它不是装饰，是"用简单符号建立体积和权重"的手艺。

规则：
- 每张图**只有 3 处**排线，位置随图变化，**角度全图统一**（比如都是 45° 向右下）
- 每处 **3-10 笔**短平行斜线，温黑，比线稿细一点
- 只在**明确需要体积/阴影**的地方——不允许蔓延到留白区

三处**默认分配**（按优先级）：
1. **小星妍身体的右下侧**（6-10 笔）——这是她的签名
2. **主物件的阴影侧**（4-8 笔）——比如书的右侧、锁盒的右侧、`?` 的内曲线
3. **地面阴影或第二个物件**（3-5 笔）——把画面"钉"在地上

**永远不能有**：
- 排线蔓延到留白区
- 全图角度不一致的排线
- 用排线填满整片区域（那是网点，不是排线）

## 中文文字规则

- 全部**手写风**（不用等宽字体、不用宋体系统字）
- 每张图**最多 2 个**中文小标签
- 每个标签**最多 6-8 字**（超了就分行或压缩）
- 位置：**贴近它注解的物件**，不用引导线（除非必要）
- 颜色：见上面颜色系统的红/蓝/橙规则
- **英文版**：如果画面上用英文（如"TOOL ERA"），用全大写 + 手写体，配英文小写副标题；不许出现汉字

## 反 slop 底线（style-dna 级别）

以下任何一条命中，图就是废图：
- 塑料高光 / 糖果反光 / 渐变
- 装饰 sparkles / 小花 / 小爱心 / 加号星（`✨` `❣️` `➕` `⭐` 全禁止）
- 伴星（除了小星妍本人 + 头顶那一个状态符号，画面上不允许出现其他任何星形）
- 复杂背景 / 家具 / 场景（编辑插画的空气感 = 白）
- 大 Dreamer 彩虹弧（Dreamer 弧永远是**紧贴头顶的小弧**）
- 排线蔓延到留白区
- 卡通腮红 / 大笑脸 / 比心 / 撒娇表情
