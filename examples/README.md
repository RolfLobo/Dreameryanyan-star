## 怎么用这份实例

**做**：
- 参考 prompt 的**结构 / 密度 / anti-slop 写法**
- 参考**反差抓手**如何锁死概念
- 参考**姿态动词**如何具体（mid-hop / braced stance / tiptoe）
- 参考**中文标签**如何精简（每张最多 2 个）

**不做**：
- 不复刻**具体构图**（不要再画"考卷翻面 / 举钥匙 / 4 把钥匙"）
- 不复刻**具体物件**（不要再画锁盒 / 书排 / 巨大 `?`）
- 不复刻**具体隐喻**（不要再用"翻面 / 化开 / 举高"）

**每次新图必须从当前文章重新发明一个奇怪但成立的隐喻。**

## 三阶段图变体

参考本对话最后一次生成的 "Tool → Copilot → Teammate" 3 段式 3:4 竖版——它展示了如何用**三个横向 band + 空间距离**表达"AI agency 的位移"，是本 IP 处理"演进式论点"的标准模板。

- **Y 轴 = 时间/演进方向**（top → bottom）
- **X 轴 = 关系距离位移**（AI 从人的手中 → 人身后 → 人身旁）
- Dreamer 弧 + 状态符号只在**最主要**的 IP 实例上打一次
- 使用**罗盘**作为状态符号（"识别范式转变"）
- 底色可选 pure white（幻灯片场景）或 cream（正文场景）
